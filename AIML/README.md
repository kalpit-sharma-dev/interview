## Suggested order — GenAI Engineer interview

1. [agentic-genai-engineer-interview-prep.md](./agentic-genai-engineer-interview-prep.md) — map JD to your stories  
2. Prepare **2 DE/DS + 2 LLM production** STAR narratives  
3. [agentic-genai-engineer-mock-interview-qa.md](./agentic-genai-engineer-mock-interview-qa.md) — 5+ answers aloud  
4. [guide-to-ai-agent.md](./guide-to-ai-agent.md) + [master-ai-agent-guide.md](./master-ai-agent-guide.md) — technical depth  
5. [agentic-genai-engineer-cheat-sheet.md](./agentic-genai-engineer-cheat-sheet.md) — day before  

## Honest readiness (GenAI IC)

| Preparation | Typical outcome |
|-------------|-----------------|
| Read AIML agent + GenAI IC docs only | ~50–60% — still need **your** DE/DS + prod LLM stories |
| Docs + mocks + real pipeline/agent project | **Strong** for many senior IC loops |
| No production LLM experience | Unlikely to meet “1–3+ years production LLM apps” bar |
